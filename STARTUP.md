# Çalıştırma

Mevcut `/workspace/ardasocialv3` klasörünü kullanın; yeni worktree oluşturmayın.
Bağımlılık kurulumu ve build gerekmez.

```sh
cd /workspace/ardasocialv3
python3 -m http.server 4173 --bind 0.0.0.0
```

Sunucunun görevler arasında çalışmaya devam edeceğini varsaymayın.
Word giriş penceresini, masaüstü projelerini, Başlat menüsünü ve görev çubuğunu kontrol edin.
Mobilde 360 ve 390 piksel genişlikte kontrol edin. Hareket azaltma tercihine uyulur.
GitHub ağ işlemleri sandbox nedeniyle desteklenen komut yetki yükseltmesini gerektirebilir. Site `main` dalına gönderilmiştir. Sonraki göndermelerde uzak depoyu yeniden kontrol edin ve mevcut dosyaları koruyun.
GitHub Pages kaynağı GitHub Actions olmalıdır.

Bulut başlangıç ayarına kaydetme denemesi `draft_not_editable` hatasıyla reddedildi; bu dosya talimatların yerel kopyasıdır.
